## 前置条件

- **Node.js** 18.x 或更高版本
- **npm** 9.x 或更高版本
- 一台电脑（Windows / macOS / Linux 均可）
- 手机和电脑处于同一局域网（或手机可访问电脑 IP）

检查 Node.js 和 npm：

```bash
node -v
npm -v
```

## 快速安装

```bash
# 克隆或进入项目目录
cd clip-relay

# 安装依赖
npm install
```

安装过程会自动下载 ws（WebSocket）、playwright 等依赖。

## 创建房间

1. 在「创建新房间」区域输入房间名称
2. 选择有效期（30分钟 / 1小时 / 2小时 / 24小时 / 永久）
3. 点击「创建房间」

创建成功后，房间会出现在列表中：

![房间列表](public/screenshot-room.png)

每个房间显示：

| 项目 | 说明 |
|------|------|
| 房间名称 | 创建时指定的名称 |
| 令牌 | 自动生成的房间令牌（房间名-12位随机字符） |
| 有效期 | 临时/永久标识 |
| 消息数 | 该房间的消息数量 |
| 在线 | 当前在线设备数 |
| 操作 | 复制链接、清空消息、删除房间 |

点击「复制链接」获取房间地址，发送给其他设备即可加入。

## 发送消息

### 打开房间

在浏览器打开房间链接：

![空房间](public/screenshot-chat.png)

### 发送文字

底部输入框输入文字，按 Enter 发送（Shift+Enter 换行）：

![发送消息](public/screenshot-chat-messages.png)

- 绿色气泡 = 本机发送的消息（右侧）
- 点击消息 = 复制全部内容
- 拖选部分文字松手 = 仅复制选中片段

### 发送图片

支持三种方式发送图片：

- **Ctrl+V 粘贴** — 截图后直接粘贴
- **点击图片按钮** — 选择文件上传
- **拖放图片** — 将图片拖入页面

图片以缩略图形式显示在消息列表中，点击可放大。

## 多设备接力

在同一房间打开链接，不同设备发送的消息会实时显示：

![双设备聊天](public/screenshot-chat-both.png)

- **绿色气泡（右侧）** = 本机发出的消息
- **浅蓝气泡（左侧）** = 其他设备发来的消息
- 新消息到达时自动弹出桌面通知（需允许通知权限）

### 局域网访问

手机访问需要知道电脑的局域网 IP：

1. 查看电脑 IP（Windows: `ipconfig`，macOS/Linux: `ifconfig`）
2. 手机浏览器打开 `http://<电脑IP>:3000/?token=<房间令牌>`

> 确保手机和电脑连接同一 Wi-Fi，且电脑防火墙允许 3000 端口。

## Docker 部署

```bash
# 构建并启动
docker compose up -d

# 查看日志
docker compose logs -f
```

自定义配置（`docker-compose.yml`）：

```yaml
services:
  clip-relay:
    build: .
    ports:
      - "3000:3000"
    volumes:
      - ./config.json:/app/config.json:ro
      - clip-relay-data:/app/data
    restart: unless-stopped
```

数据通过 volume `clip-relay-data` 持久化，重启不丢失。

## 配置文件说明

项目根目录下的 `config.json`：

```json
{
  "defaultToken": "clip-relay",
  "port": 3000,
  "maxImageSize": 5242880,
  "domain": "",
  "adminPassword": ""
}
```

| 字段 | 说明 |
|------|------|
| `defaultToken` | 默认房间令牌 |
| `port` | 服务端口 |
| `maxImageSize` | 单张图片最大字节数（默认 5MB） |
| `domain` | 公网域名（配置后复制链接出现公网选项） |
| `adminPassword` | 管理员密码（留空则首次启动随机生成） |

> 忘记密码：查看 `config.json` 中的 `adminPassword` 字段，或删除该字段重启服务重新生成。

## 常见问题

### Q: 手机无法访问电脑上的服务？

1. 确认手机和电脑连接同一 Wi-Fi
2. 确认电脑防火墙允许 3000 端口
3. 使用正确的局域网 IP（不是 localhost）
4. 有些路由器开启了 AP 隔离，需关闭

### Q: 如何让外网访问？

使用 Cloudflare Tunnel：

```bash
# 安装 cloudflared
cloudflared tunnel login
cloudflared tunnel create clip-relay
cloudflared tunnel route dns clip-relay relay.yourdomain.com
```

配置 `~/.cloudflared/config.yml` 后将域名填入管理后台「域名设置」。

### Q: 服务占用内存多少？

空载时约 30-40MB，正常使用约 50-80MB，非常轻量。

### Q: 如何修改端口？

修改 `config.json` 的 `port` 字段，或设置环境变量 `PORT=8080`。

### Q: 数据存在哪里？

SQLite 数据库文件存储在 `data/` 目录下，直接复制即可备份。

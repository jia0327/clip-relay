# ClipRelay 部署指南

三种部署方案：本地、Docker、Cloudflare。

---

## 方案对比

| | 本地部署 | Docker 部署 | Cloudflare 部署 |
|---|---------|------------|-----------------|
| **适合场景** | 个人临时使用 | NAS/服务器常驻 | 追求零运维 |
| **前置要求** | Node.js 18+ | Docker | Cloudflare 账号 |
| **外网访问** | 仅局域网 | 需另配内网穿透 | ✅ 自带公网 |
| **启动** | `npm start` | `docker compose up -d` | GitHub Actions 自动 |
| **难度** | ⭐ | ⭐⭐ | ⭐ |
| **费用** | 免费 | 免费 | 免费 |

## 本地部署

适合个人电脑临时使用。

### 环境要求

- Node.js 18+
- npm 9+

### 启动

```bash
npm install
npm start
```

终端输出管理员密码，浏览器访问 `http://localhost:3000/admin` 登录。

### 局域网访问

1. 查本机 IP：Windows `ipconfig`，macOS/Linux `ifconfig`
2. 手机访问 `http://<IP>:3000/?token=<房间令牌>`

---

## Docker 部署

适合 24 小时在线的设备（NAS、VPS、N1 等）。

### 启动

```bash
docker compose up -d
docker compose logs -f
```

首次启动会输出管理员密码。

### 数据持久化

数据存储在 Docker volume 中，重启不丢失。

---

## Cloudflare 部署

零服务器维护，完全托管在 Cloudflare。

详见 [Cloudflare 部署指南](./cloudflare-deploy.md)

### 快速开始

1. Fork 本仓库
2. 在 Cloudflare 获取 3 个参数
3. 在 GitHub 配置 Secrets
4. 手动触发 Actions 部署

---

## 配置

`config/config.json`:

```json
{
  "defaultToken": "clip-relay",
  "port": 3000,
  "maxImageSize": 5242880,
  "domain": "",
  "adminPassword": ""
}
```

| 字段 | 说明 |
|------|------|
| defaultToken | 默认房间令牌 |
| port | 服务端口 |
| maxImageSize | 图片最大字节数（默认 5MB） |
| domain | 公网域名 |
| adminPassword | 管理员密码（留空自动生成） |

## 常见问题

### Q: 三种方案选哪个？

- 自己用、电脑不常开 → **本地部署**
- 24 小时在线 → **Docker 部署**
- 不想维护服务器 → **Cloudflare 部署**

### Q: 忘记管理员密码？

查看 `config/config.json` 的 `adminPassword` 字段。

### Q: 数据备份？

- 本地/Docker：备份 `data/` 目录
- Cloudflare：数据在 D1 数据库
